# Découvrir un module comme un utilisateur curieux

**Persona**: au choix (`personas/agent-accueil.md` par défaut)
**Module**: _à préciser dans la demande_ (calendrier, projets, messages, e-learning, paramètres, tableau de bord).
**Objectif métier**: « Je ne connais pas ce module: je regarde à quoi il sert et j'essaie ses fonctions principales. »

## Contexte
Mission d'exploration: aucun objet précis n'est imposé. Sert à repérer ce que les missions du module devront couvrir.

## Données à produire
| Op | Objet | Description | Critère de réussite |
|---|---|---|---|
| créer | Un exemple de chaque type d'objet principal du module | portant `[QA-xxxx]` | visible à l'écran ; en base si les tables sont identifiables |
| modifier | Un de ces exemples | changer un champ significatif | |
| supprimer | Uniquement ce qui a été créé dans cette session | | |

## Ce qu'on veut apprendre
Quelles sont les fonctions du module ? Lesquelles sont évidentes, lesquelles cachées ? À la fin, proposer dans « Suggestions » une ou deux missions à écrire pour ce module (au format de `missions/_modele.md`).
